This Wordle clone was a group assignment for my Program Construction II class. For this I and my team member, Aayush Adhikari, were tasked with recreating Wordle from scratch. This included the GUI using CLI and everything else in C++.

I implemented the main GUI, key logging, button focus for gameplay reasons, the player class, the ability to load and save the player information, added sound for winning and losing. The button focus was due to the Enter key not working on the keyboard so switching the focus between the Delete, Enter, and New Game buttons was the work around we used.

Aayush did much of the gameplay loop, loading the dictionary, setting up dark mode, the GUI for displaying the player's stats.
